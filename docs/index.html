Phase 1

Phase 1 - foundation: core library and CI are in place. Sorting is not enabled yet. Config builder coming.

What it does

After N days, your liked songs are matched against your rules - artist, language, genre, release year, explicit - and moved into playlists you already have.

  • Never creates playlists unless a rule allows it.
  • Dry-run by default, so you see what would happen first.
  • Never loses a liked song: journal, verify, and restore.

How it works

  1. Fork the repository.
  2. Create your own Spotify Developer app.
  3. Add two GitHub secrets.
  4. A daily GitHub Action does the sorting. No server involved.
